# CMS + E-commerce Template (CMS Primary)

This template provides a headless WordPress setup with **both CMS and WooCommerce features**. The CMS/blog is the primary focus, with the homepage showing blog content.

## What's Included

### Everything from CMS-only AND E-commerce-only templates:
- All WordPress core features
- All CMS plugins (WPGraphQL, ACF, SEO, etc.)
- All WooCommerce plugins (payments, shipping, reviews, etc.)
- All custom plugins (gp-featured-items, gp-most-popular, gp-social-poster, gp-headless-config)

## Homepage Configuration

- **Homepage Type:** Blog/Content
- **Primary Focus:** Content marketing with integrated shop
- **Navigation:** Blog-first, shop secondary

## Usage

```bash
gpp add cms cms-ecommerce
```

This variant is ideal for:
- Content sites with a shop section
- Blogs that sell products
- Marketing sites with e-commerce

## Environment Variables

Set `ENABLE_WOOCOMMERCE=true` in `.env` to install WooCommerce plugins.
