# Marketplace Assets

This directory contains assets for the Strapi Marketplace listing.

## Required Assets

### Logo (`logo.png`)

- **Size:** 128x128 pixels
- **Format:** PNG with transparent background
- **Purpose:** Displayed in the marketplace listing and plugin settings

### Cover Image (`cover.png`)

- **Size:** 1200x630 pixels
- **Format:** PNG or JPG
- **Purpose:** Featured image for marketplace listing

## Optional Assets

### Screenshots

Place screenshots in the `screenshots/` directory:

```
marketplace/
├── screenshots/
│   ├── screenshot1.png
│   ├── screenshot2.png
│   └── screenshot3.png
```

**Recommended specifications:**
- **Size:** 1280x800 pixels (or similar aspect ratio)
- **Format:** PNG
- **Quantity:** 3-5 screenshots recommended
- **Content:** Show key features and UI

## Asset Checklist

- [ ] Logo (128x128 PNG)
- [ ] Cover image (1200x630 PNG/JPG)
- [ ] At least 2 screenshots
- [ ] All images are high quality and professional
- [ ] Screenshots demonstrate key functionality

## Tips for Great Marketplace Assets

1. **Logo:**
   - Keep it simple and recognizable
   - Ensure it's readable at small sizes
   - Use your brand colors

2. **Cover Image:**
   - Include the plugin name
   - Show a preview of the main feature
   - Use consistent branding

3. **Screenshots:**
   - Annotate key features
   - Show real content (not lorem ipsum)
   - Highlight unique value propositions
   - Include before/after comparisons if relevant
