# iOS App Store Screenshots

## Required Sizes

### iPhone Screenshots (Required)

| Device | Display Size | Resolution | Aspect Ratio |
|--------|-------------|------------|--------------|
| iPhone 15 Pro Max / 14 Pro Max | 6.7" | 1290 x 2796 | 9:19.5 |
| iPhone 15 Pro / 14 Pro / 13 Pro Max | 6.5" | 1284 x 2778 | 9:19.5 |
| iPhone 8 Plus / 7 Plus / 6s Plus | 5.5" | 1242 x 2208 | 9:16 |

**Note**: You must provide 6.7" OR 6.5" screenshots. 5.5" is optional but recommended.

### iPad Screenshots (If Universal App)

| Device | Display Size | Resolution |
|--------|-------------|------------|
| iPad Pro 12.9" (6th gen) | 12.9" | 2048 x 2732 |
| iPad Pro 11" | 11" | 1668 x 2388 |

## Screenshot Guidelines

### Quantity
- Minimum: 1 screenshot per device size
- Maximum: 10 screenshots per device size
- Recommended: 5-8 screenshots

### Content Requirements
- Must be actual screenshots of your app
- Can include text overlays and device frames
- No alpha/transparency
- No rounded corners in the actual image file

### Best Practices

1. **First Screenshot**: Show your main value proposition
2. **Feature Highlights**: One screenshot per key feature
3. **Text Overlays**: Keep text brief and readable
4. **Consistency**: Use consistent style across all screenshots
5. **Localization**: Consider different screenshots for key markets

### File Naming Convention

```
01_feature_name_6.7.png
02_feature_name_6.7.png
03_feature_name_6.7.png
...
01_feature_name_6.5.png
02_feature_name_6.5.png
...
```

## App Preview Videos (Optional)

| Spec | Requirement |
|------|-------------|
| Duration | 15-30 seconds |
| Format | .mov or .mp4 |
| Codec | H.264 |
| Resolution | Match device screenshot resolution |
| Frame Rate | 30 fps |
| Audio | AAC, stereo |

### Video Best Practices
- Show app in action, not just static screens
- Add captions for accessibility
- No "Download now" calls-to-action
- Can use device frames
